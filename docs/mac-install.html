1. 安装与打开

  1. 双击 绮绘预演台V1.5-macOS-arm64.zip 解压，找到绮绘预演台V1.5.app。
  2. 将 .app 拖入 Finder 的“应用程序”文件夹。请移动整个应用包，保留内部内容。
  3. 从“应用程序”打开。若出现绮绘画布连接窗口，只在本地制作时选择“暂不连接，直接进入”。
  4. 全新数据目录从空场景开始。添加人物和相机后，点击保存图标或按 Cmd + S 保存。

本包提供 .app 与离线教程；Windows 的 .exe 不用于 Mac。Intel Mac 请勿使用这个 arm64 包。

首次打开提示：此版本尚未经 Apple 公证。若系统拦截，请先确认文件来源，尝试打开一次，再到“系统设置 → 隐私与安全性”找到此应用的提示，选择“仍要打开”并按系统要求确认。若未出现该入口，请保留完整提示供排查。

2. 数据和资产放在哪里

内容Mac 目录
项目与本地素材库~/Library/Application Support/YuyantaiDirector/state
自定义人物、模型、动作和姿势~/Library/Application Support/YuyantaiDirector/Assets

在软件“文件”菜单选择“打开数据文件夹”或“打开资产文件夹”即可查看。也可在 Finder 使用“前往 → 前往文件夹”，输入上面的路径。

资产目录按 characters、models、motions、poses 分类。把兼容文件放入对应目录后刷新资产；不要把自己的模型放入 .app 内部。具体格式和 Mixamo 导入步骤见完整教程第 13 节。

备份：先保存并退出软件，再复制整个 ~/Library/Application Support/YuyantaiDirector/ 目录。网页旧项目和 Windows 项目不会自动同步到 Mac；跨设备迁移时，还要带上所用外部资产并保持相对路径。

4. 开始制作

先添加一个人物、一段动作和一台相机，做一个 3–5 秒的预演。右上角没有相机时显示“暂无相机”，需要先添加相机才能拍摄或导出。

完整使用教程包含关键帧、骨骼动画、定格接续、多镜头、背景和保存迁移步骤。页面可离线阅读；在浏览器按 Cmd + P 可打印或保存为 PDF。
