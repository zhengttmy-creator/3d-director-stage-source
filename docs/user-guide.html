01安装与首次启动

Windows 提供安装版和便携版；M 系列 Mac 提供 Apple Silicon 原生应用。各版本使用同一套编辑功能，安装方法和数据目录有所不同。

Windows

日常固定使用推荐安装版；临时试用可以直接运行便携版。

版本启动方法
安装版
绮绘预演台V1.0-Setup-x64.exe		双击安装包，选择安装位置，完成后从桌面或开始菜单启动。
便携版
绮绘预演台V1.0-x64.exe		放入准备长期保留的文件夹后双击。首次展开程序可能需要稍等，不要连续重复启动。

Mac：Apple Silicon / M 系列

适用于 macOS 11 或更新版本的 M 系列 Mac；本包为 arm64 原生版，不是 Intel 版本。

  1. 下载并双击 绮绘预演台V1.0-macOS-arm64.zip 解压。压缩包内含应用 .app、Mac 安装说明和离线教程。
  2. 将绮绘预演台V1.0.app拖入 Finder 的“应用程序”文件夹，再从应用程序打开。该文件用于 M 系列 Mac，Windows 的 EXE 不能在 Mac 直接运行。
  3. 本版本尚未经 Apple 公证。如首次打开被系统拦截，在确认文件来源后，打开“系统设置 → 隐私与安全性”，找到对应提示并选择“仍要打开”，按系统要求确认。需先尝试打开一次，相关入口才可能出现。

Mac 使用 ZIP 内的 .app，不需要运行安装器。请保留整个应用包，勿改动其内部文件；自己的模型、动作和姿势放入第 13 节所述的资产目录。

进入编辑器

  1. 启动时如出现绮绘画布连接窗口，纯本地使用选择“暂不连接，直接进入”。内置模型、动作和本地导出不要求登录。
  2. 全新数据目录从空场景开始，没有预置人物和相机；已有使用记录时会载入最后保存的本地项目。
  3. 第一次建立场景后，点击左上角保存图标。退出、刷新或升级前先保存。
  4. 本教程随发行文件提供，也可以从软件的“帮助 → 使用教程”或 F1 打开。Mac 键盘可能需要 Fn + F1；也可直接使用帮助菜单。在浏览器中按 Windows Ctrl + P 或 Mac Cmd + P 可打印或另存为 PDF。

便携版不等于所有数据都在 EXE 旁边。安装版与便携版在同一 Windows 用户下共用桌面版项目数据；自定义资产目录可能位于程序旁，具体路径以“打开资产文件夹”显示为准。

Mac 项目和自定义资产保存在当前用户的 ~/Library/Application Support/YuyantaiDirector/，更换 .app 不会把这些内容打进应用包。详细备份方法见第 14 节。

02第一个预演：五分钟流程

放人物加动作设相机播放检查保存与导出
  1. 左侧资产 → 角色选择“男性 · 标准”或其他体态，点击场景地面放置。
  2. 顶部切换“动态预演”，把播放头放在 0 秒，先摆好人物初始位置。
  3. 在人物时间轴行点击 “+” → “添加动作到时间轴”，选择“行走”。确认后，动作会出现在人物的“动作”轨道。
  4. 左侧切到机位，点击“正面中景”，再点击场景中的人物，按界面提示完成机位设置。
  5. 在预览窗口选择这台相机。点击时间轴播放按钮，检查动作和构图；先单击时间轴空白处再按 Space 也可播放。
  6. 在底部“镜头剪辑”点击“+”，选择该机位并设置拍摄时长。保存项目后，点击“导出视频”，按镜头轨道生成视频，再点击“保存到本地”。

先做一段 3–5 秒的小片段验证流程，再增加角色、灯光、背景和镜头。地面网格是编辑辅助，不是已放入的模型。

03认识工作区

区域用途
顶部栏保存项目、切换静态/动态预演、拍摄或导出视频。
左侧资产栏添加人物、物体、背景和机位；标题旁的资产文件夹入口用于查看本地导入目录。
中央场景放置和选择对象，拖动位置、旋转、缩放控件；这是搭建空间的主工作区。
右上角预览检查指定机位的画面，或预览镜头剪辑。无相机时显示“暂无相机”。
右侧对象与属性从列表选中对象，调整精确数值、人物颜色、相机参数或场景环境。
底部时间轴动态预演时安排动作、对象关键帧和镜头剪辑。展开人物或相机行可查看子轨道。

静态预演适合摆位和固定构图；动态预演用于动作、运镜和时间轴。动态模式下先看清当前时间，再修改对象，避免把初始摆放误写到后面的帧。

04快捷键速查

快捷键取决于焦点所在区域。编辑数值或文字时先按 Enter 完成输入，或单击场景/时间轴空白处，再使用编辑快捷键。

下表主要按 Windows 键名标注。Mac 的保存、撤销、重做、复制和粘贴分别使用 Cmd + S、Cmd + Z、Cmd + Shift + Z、Cmd + C / V；空格、数字工具键与字母导航键保持相同。Mac 键盘的 delete 可用于这里的退格删除。

当前版本使用数字键切换工具：0 选择、1 移动、2 旋转、3 缩放。W、E 属于视角移动按键，并非 UE 的 W/E/R 工具映射。

鼠标操作

空白处左键拖动旋转观察方向，右键拖动平移，中键拖动推近/拉远；选中对象时抓住轴柄进行变换。按住 Alt 或 Ctrl 滚轮调整视野，导演视角也可用 − / + 调整视野。

Mac 调整视野仍使用 Option 或 Control + 滚轮，不能把这里的 Control 一律替换成 Command。使用触控板时可通过辅助点按打开右键菜单；涉及中键拖动的操作，用外接鼠标更方便。

05人物、物体与变换

添加与选择

内置人物提供男性、女性各 6 种体态：标准、少年、儿童、纤瘦、健壮、丰腴。点击人物卡片后，在地面点击放置；通过右侧对象列表也能选择被遮挡的对象。按住 Shift 单击可多选。

位置、旋转、缩放

  1. 选择对象，按 1、2、3 切换工具。拖动单轴柄只改变该轴；右侧 X/Y/Z 输入框适合精确输入。
  2. 位置单位为米；Y 是上下方向，X/Z 是地面方向。不要把本软件的轴方向与其他软件的默认坐标系混淆。
  3. 旋转按 X/Y/Z 分别调整。缩放可改变整体大小或指定轴；改变人物体型时优先选择对应的内置人物。

在人物属性中的颜色选择色板或输入 HEX 值；“恢复原色”可以还原。点击场景空白处后，可在环境属性中调整背景颜色、地面、网格和灯光。

06时间轴与关键帧

项目最长 30 秒。时间轴上的秒数是项目时间，帧数由项目帧率决定。建议先确定帧率，再细调关键帧和镜头切换。

做一个位置动画

  1. 切到动态预演，暂停播放，把播放头移到 0 秒，摆好人物起点。
  2. 展开人物行，点击“位置”右侧的菱形，手动记录起点。
  3. 将播放头移到 2 秒，把人物移动到终点。非 0 秒改变位置会自动记录关键帧。
  4. 回到 0 秒播放，人物在起点和终点之间移动。旋转和缩放使用相同流程。

自动标点规则：动态模式下，非 0 秒编辑人物、物体、相机或注视点会按对应属性记录关键帧；首次位置动画会补上 0 秒起点。0 秒尚无轨道时用于初始摆放，已有轨道时更新当前帧。自由浏览导演视角不会记录相机运动。

手动标点与修改

位置、旋转、缩放，以及相机的位置、注视点、视野、画面倾斜都有手动菱形按钮。空心表示该时刻未记录，实心表示已有关键帧；再次点击会更新数值。暂停播放并解锁对应对象后再编辑。

拖动菱形可改变关键帧时间；选中后用 Delete 或 Backspace 删除。调整时间轴缩放后再拖短距离，能减少误选和时间跳动。

调整运动节奏

打开轨道的曲线入口，选择需要编辑的相邻关键帧区间，再设置“线性”“缓入”“缓出”“缓入缓出”或“保持”。线性为匀速，保持会在下一关键帧前保持旧值；曲线影响该段插值，不会自动增加新的关键帧。

07动作库与人物位移

  1. 选择人物，将播放头放到动作起始时间。
  2. 点击人物轨道的 “+” → “添加动作到时间轴”。
  3. 在“动作”页搜索名称。卡片显示角色预览，鼠标停留或键盘聚焦时播放动作。
  4. 选择动作并确认。拖动片段改变开始时间，拖动边缘调整片段范围；片段设置中可调整可用的循环、速度等参数。

内置 16 个动态动作，包括行走、跑步、待机、下蹲、起身、潜行、侧步、跳跃、翻滚、闪避、点头、摇头和舞蹈；行走、跑步另有路径选项。静态姿势在相邻标签中选择。

动作类型使用方式
原地动作四肢运动，根位置基本不变；需要走位时配合人物的位置关键帧。
动作自身带位移按动作数据移动；开启循环后累计地面方向的位移，避免每轮回到起点，结束后保持最终位置。
路径动作人物沿位置轨道行进。先摆好路径/位置关键帧，再使用对应的行走或跑步路径选项。

动作卡片预览会把人物居中，便于观察四肢；实际行进距离以时间轴播放为准。给已有根位移的动作再叠加位置动画时，请检查是否移动过快。身体上下起伏仍随动作循环，不会每轮累计下沉或升高。

当前没有足部 IK 锁定；走位速度与步幅不匹配时可能出现滑步，应调整动作速度、路径距离或片段时长。

08自定义姿势与骨骼动画

固定姿势

打开动作窗口的“静态姿势”标签。“常用姿势”提供站立、蹲姿、坐姿和跪姿等；“从动作选帧”可把动态动作中的某一帧取作姿势。坐姿只包含人物，不会自动创建椅子。

  1. 点击“自定义姿势”，选取场景中的关节控制点，拖动调整；右侧姿势属性可作进一步修改。
  2. 填写片段名称和时长。点击“保存片段”写入当前时间轴。
  3. 需要下次复用时，另外点击“保存到本地”，加入“我的姿势”。这和保存当前项目是两件事。
  4. 需要分享时点击“导出 JSON”；接收方用“从本地读取”导入 .octomotion.json 文件。

用多个姿势组成骨骼动画

  1. 在人物“动作”轨道点击菱形，或在动作片段设置中选择“编辑骨骼关键帧”；姿势编辑器也可以“转为骨骼动画”。
  2. 设置“骨骼关键帧时间”。这里的 0 秒是本片段的起点，不一定是整个项目的 0 秒。
  3. 调整关节，点击“添加关键帧”；该时刻已存在时按钮显示“更新关键帧”。
  4. 把关键帧时间移到后面，再调整姿势并记录。至少两个不同时间、不同姿势，才会形成姿态变化。
  5. 播放检查，再点击“保存片段”或“添加到时间轴”完成编辑，最后保存项目。

动作轨道的小菱形与编辑器同步。可以直接拖动指定的骨骼关键帧，只改变该帧的时间，不会拖走其他关键帧；不能拖到片段范围外或另一骨骼帧已占据的时间。

骨骼帧记录全身姿势，帧与帧之间进行平滑插值；位置、旋转、缩放轨道仍可独立控制整个人物。“保存到本地”与“导出 JSON”可保留完整骨骼动画供后续复用。

09定格并接续新动作

想让人物“走到一半停住，再抬手”，可以截断原动作后半段，从当前完整姿势继续编辑。

  1. 播放或拖动播放头，找到原动作中要停住的那一帧，暂停。
  2. 打开该动作片段设置，点击“在此帧结束并接续”。
  3. 原动作保留到当前时刻，后半段被截去；后面出现“姿势接续”片段，含一个当前全身姿势的关键帧。
  4. 编辑接续片段，把“骨骼关键帧时间”移到后面，修改手臂等关节，再点击“添加关键帧”。不要只改初始定格帧。
  5. 保存片段后播放，检查原动作、定格姿势和新姿势的衔接。

起始定格帧用于保留原动作的接点，不能用记录按钮覆盖或删除；仍可单独拖动它调整时间，不会带动其他帧或前一段动作。只有一帧时，人物保持这个姿势；新增后续帧后才产生姿态过渡。时间轴中原有的位置、旋转、缩放关键帧仍然存在，必要时一起调整。

接上另一个预设或 Mixamo 动作

在接续片段设置中调整“接续片段时长”和“衔接过渡”，点击“衔接下一个动作”选择动作。先在后方留出足够空白；过渡最长 24 帧，设为 0 则直接切换。普通后续动作会按接续姿势对齐根位置与水平朝向，路径动作仍由位置轨道控制。

10相机与画面构图

添加对准人物的机位

  1. 进入左侧机位分类，选择“正面中景”“正面特写”“侧面近景”等预设。
  2. 按提示在场景或对象列表中选择人物。过肩镜头还需要依次确定前景角色与注视对象/注视点。
  3. 完成后在右上角预览选择该机位，检查画面是否正确；继续调整相机位置、注视点、视野与画面倾斜。

“当前视角”适合把已经摆好的导演视角保存为相机。没有相机时，可点击预览区域的“添加相机”，或者在底部镜头剪辑轨道新建。

区分导演视角和机位画面

导演视角用于绕场景观察和编辑，移动它不会自动修改拍摄相机。进入指定机位视角后，导航按键调整的是该机位。要返回搭建状态，按 Esc 退出机位预览，或使用视口底部视角下拉选择“导演视角”。

需要改人物时明确选择人物并使用变换控件或属性；需要改机位时在对象列表明确选择相机。WASD 是视角导航，不是人物走位按键。动态模式非 0 秒编辑机位参数会按相应轨道记录关键帧；只想设初始构图时先回到 0 秒。

相机全部删除后，预览显示“暂无相机”，拍摄和视频导出不可用。添加至少一台有效相机后再导出。

11多镜头剪辑

时间轴中每台相机各占一行，拍摄片段直接显示在对应的相机根行。不同相机片段可以重叠，按上方轨道优先的规则播放：上面的启用片段覆盖下面的；上方片段结束或停用后，继续播放下方仍有效的镜头。下层使用当前全局时间，不会从头重播。展开相机行后，可编辑位置、注视点、视野等运镜关键帧。名称旁的时长是该机位启用片段的安排时长合计，包含被上层覆盖的部分；停用片段不计入，未添加片段时显示 0.00s。

  1. 在对应相机行点击“+ 添加拍摄片段”，或在行标题“+”菜单选择“添加拍摄片段”。也可右键该行空白处，以点击的时间为开始位置。
  2. 确认相机，填写“开始（秒）”“拍摄时长（秒）”，点击“添加拍摄片段”。底部“镜头剪辑”工具栏可添加其他机位的片段，或点“新建相机”从当前导演视角建立机位；“添加片段”从播放头向后寻找该相机行内的空闲时段，不会被其他相机行占用。
  3. 拖动镜头块移动整段，拖动左右边缘修改开始或结束时间。不同相机行之间允许重叠，同一相机行内不可重叠；每段至少一帧，总范围不超过 30 秒。
  4. 单击某台相机行中的片段，在底部设置栏修改“开始”“拍摄时长”，有效数值即时生效；无效范围会显示提示并保留原片段。点击“追加镜头”继续安排下一段；双击或右键片段可更换相机或调整启用状态。更换相机后，片段会移到相应行。
  5. 点击底部“镜头剪辑”工具栏的“预览”，主画面进入镜头轨道视角，再按空格或播放按钮检查切镜头；底部视角菜单也可选择“镜头轨道”。
操作结果
聚焦镜头块后按 ← / →移动该片段 1 帧；按住 Shift 移动 10 帧，播放头保持不变。
取消镜头块上的复选框暂时禁用该段镜头，保留相机和片段。
镜头设置中的“删除镜头”仅移除这一段剪辑，保留相机。
镜头块垃圾桶 / “删除相机”删除对应相机，同时清理引用该相机的镜头段。
选中镜头块后按 Delete / Backspace与“删除相机”一致；要只移除一个镜头段，请使用镜头设置中的“删除镜头”。

导出固定渲染“镜头轨道”，手动查看其他相机不会改变成片。请从 0 秒起连续安排启用片段；起始或中间有空档时，导出窗口会指出缺失时段并禁用导出。视频时长取最后一个启用片段的结束时间，未使用的项目尾段不渲染。

12上传、关闭和删除背景

  1. 左侧切到背景，点击“上传背景”，选择 PNG、JPG/JPEG 或 WebP 图片。支持一次选择多张，单张不超过 16 MB。
  2. 上传完成后，图片出现在背景库。点击缩略图，选择“设为平面背景”或“设为 720 全景背景”。
  3. 平面背景适合普通照片；全景背景应使用适合全景映射的图片。普通照片强行铺满全景会拉伸，需根据构图选择模式。
  4. 需要暂时隐藏时，点击“关闭背景”。素材保留在库中，之后可以重新应用；场景中的关闭操作可以撤销。
  5. 需要从素材库移除时，点击图片右上角的删除图标；若正在使用这张图，当前背景会同步关闭。

误删后立即点击本面板的“撤销删除”恢复最近删除的素材，再按需重新设为背景。上传素材会保存在本地；背景在场景中的选择和关闭状态需要保存项目。不要把“关闭背景”和“删除素材”混为一项操作。

13导入 Mixamo 与模型资产

直接导入动作或姿势

打开动作库的导入入口，选择兼容的 Mixamo .fbx 动作，或本软件导出的 .octomotion.json 备份。预览并确认后加入本地库，再添加到人物时间轴。需要固定坐姿或蹲姿时，可以从导入动作中选取一帧，保存为自己的姿势。

把资产放入文件夹

  1. 点击“文件 → 打开资产文件夹”，或资产栏旁的文件夹入口。使用界面显示的实际目录。
  2. 按下表把文件放入对应子文件夹。模型的贴图和数据文件保持原来的相对路径；推荐每套模型单独一个子文件夹。
  3. 等待约 5 秒扫描，或点击“文件 → 刷新资产” / 资产窗口的“刷新”。导入失败时查看该窗口的错误说明。
  4. 在对应分类搜索文件名称并添加。若替换了已经使用的文件，重新添加该资产或重新打开项目后再检查。
子目录文件出现在

与模型同名的 PNG/JPG/WebP 可用作缩略图。目录和文件名支持中文。普通未绑定骨架的模型不能直接套用人物动作，任意其他骨架也不保证兼容；导入后先用短片段检查手脚、朝向和身高。

已经被项目引用的文件，请保留文件名和位置。分享或迁移时把相应 Assets 文件夹一并提供。

Mac 的自定义资产固定保存在 ~/Library/Application Support/YuyantaiDirector/Assets。同样通过“文件 → 打开资产文件夹”进入，再按分类放入文件；无需把资产放进 .app 内部。

14保存、备份与迁移

日常保存

点击顶部保存图标，或 Windows Ctrl + S、Mac Cmd + S。等待“已保存”再退出。保存动作片段、保存姿势库和保存整个项目分别完成不同工作；片段编辑结束后仍应保存项目。

完整备份桌面版

  1. 保存项目，打开“文件 → 打开数据文件夹”，记下位置；另开“打开资产文件夹”，确认外部资产所在位置。
  2. 退出软件，再把完整数据目录和自定义资产目录复制到备份位置。建议按日期命名备份文件夹。
  3. Windows 默认数据目录为 %APPDATA%\YuyantaiDirector\state；外部资产可能在程序旁的 Assets，也可能在 %APPDATA%\YuyantaiDirector\Assets。Mac 默认数据目录为 ~/Library/Application Support/YuyantaiDirector/state，外部资产为同级 Assets 文件夹。
  4. 恢复时先退出软件并备份当前目录，再恢复对应数据；自定义资产的结构、文件名和相对位置应保持一致。

在 Mac Finder 中可用“前往 → 前往文件夹”，输入 ~/Library/Application Support/YuyantaiDirector/ 查找上述目录。退出软件后备份整个目录即可同时保留 Mac 的项目与外部资产。

浏览器网页、桌面 EXE 和浏览器扩展的数据不是同一份。此前在 127.0.0.1:4210 网页里做的项目不会自动出现在 EXE 中；安装后显示空场景不代表旧项目被删除。先在旧版保存，并确认旧版服务的实际数据目录，再进行迁移。

旧网页版的默认目录为其程序内的 web/state，但自定义启动方式可能使用其他目录，不能仅凭端口号判断。确认旧目录后，退出两边程序并备份，将旧数据迁入桌面版数据目录，同时迁移外部资产；不要只复制 EXE。

本地保存不会自动同步到 GitHub，也不等于上传到绮绘画布。项目交接应提供项目数据及所用外部资产；仅交付视频时提供导出的成片即可。

15导出与常见问题

导出视频

  1. 至少添加一台相机，先播放检查角色、背景、关键帧与镜头切换。
  2. 在“镜头剪辑”安排每台相机的拍摄时段，再点击“导出视频”。无论一台还是多台相机，导出来源都固定为“镜头轨道”。
  3. 确认窗口显示的总时长和启用片段数，设置帧率与清晰度后开始导出。要改时长，先回到镜头轨道调整片段；轨道需从 0 秒起连续覆盖。导出期间保持软件打开。
  4. 生成完成后预览视频，点击“保存到本地”，选择保存位置。输出不包含编辑工具、控制点和界面。

拍摄静帧可使用顶部拍摄入口；结果进入镜头素材。截图/视频添加到绮绘画布需要另外连接账号，本地编辑和导出可以跳过连接。

W/E/R 没有切换工具当前版本使用 0/1/2/3 切换选择、移动、旋转、缩放。WASD、Q/E 用于视角导航。
拖动后相机画面没变确认正在编辑实际相机，而不是浏览导演视角；检查预览窗口是否选择了正确机位或镜头剪辑。
“正面中景”没对准人先点击预设，再按提示选择拍摄对象；过肩镜头需完成前景与目标两步。必要时从对象列表选择人物。
只有姿势，没有动画一个骨骼帧只会保持姿势。到后面的片段时间调整关节，点击“添加关键帧”，保存片段后再播放。
人物走得太快、滑步或回原点确认动作是原地、带根位移还是路径版本，检查是否叠加了位置轨道；检查循环设置及源文件是否包含期望位移。
关键帧拖不动先停止播放并解锁对象，放大时间轴，抓住菱形本身。骨骼帧不能越过片段范围，也不能与另一帧重合。
镜头删除后预览为空可能删除了最后一台相机；点击“添加相机”恢复。只想临时关闭某段镜头时使用复选框。
模型或动作不在库中确认实际资产目录、分类和文件格式，再刷新资产；模型贴图/数据缺失时恢复原相对路径，不兼容骨架需先作适配。
背景上传失败使用有效 PNG/JPG/WebP，单张不超过 16 MB；检查图片本身能否打开。错误提示保持在背景面板，可更换图片重试。
导出失败或速度很慢先尝试短时长、标准清晰度，确认资产已加载完毕，并减少复杂模型。长时高分辨率导出消耗更多显存和内存。
启动 EXE 后看不到网页旧项目两者使用不同数据目录。参照第 14 节先备份和迁移，不要反复保存空场景覆盖未知目录。

本教程对应当前 Windows 与 Apple Silicon Mac 本地版本。任意外部模型、非 Mixamo 骨架及所有设备上的长时高分辨率导出不保证兼容；遇到新资产时先用一个人物、一台相机和短时间轴验证。
